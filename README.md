## Recent updates

- **v0.1.11:** Automatic nearby attendance after verification, without a separate Help action; foreground resume respects an explicit Bluetooth pause.
- **v0.1.10:** Lecture-bound cascading attendance and a CR confirmation before closing the lecture.
- **v0.1.9:** Academic-calendar holidays and “Enjoy your holidays” across class views.
- **v0.1.8:** Faster attendance preparation and leaner account-scoped roster polling.
- **v0.1.7:** Bounded Bluetooth sweeps, staggered retries and compatible authenticated native-mobile protocol.
- **v0.1.6:** Shorter startup delays and account-bound cached profile loading.

Install v0.1.11 for all the latest Android changes. Previous versions are preserved for reference; classroom Bluetooth testing is still required. No instant recognition, exact-distance, anti-jamming or classroom-capacity guarantee is made.

## Installation and updates

These versions share the BYG release signing certificate. A device running a release-signed BYG APK can update in place. Older debug-signed APKs require a one-time uninstall/reinstall; back up local-only checklist/preferences first. Cloud records remain linked to the same account.

## Source code

This repository contains **download links, release notes and APK assets only**. BYG's application source, credentials and signing key are not published here. GitHub's automatic “Source code” ZIP/TAR downloads contain only this public documentation repository, not the Android application project.
